A closer look

Engineering notes.

Open a layer to see what goes into it.

01Native client architecture

The desktop side is written in C++ and uses Windows APIs. Memory management, threading and the client lifecycle belong to this layer. The interface is only the visible part of the work.

02Accounts and access

Discord sign in connects the web account with client access. Account pages and license management give the platform a common identity across the website and desktop software.

03The web application

React components, TypeScript and Next.js form the web layer. Navigation, account screens and responsive layouts share the same application structure instead of being separate, disconnected pages.

04Delivery and infrastructure

Publishing is part of the product. Cloud infrastructure, the launcher and release information connect development with the version people actually use. This portfolio itself is a static Next.js export on GitHub Pages.
